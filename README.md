# DrawView

DrawView is a drawing application for Android that lets you unleash your creativity. Built with Jetpack Compose and Google's `androidx.ink` library, it offers a smooth and intuitive drawing experience.

## 🎨 Features

* **Versatile Drawing Tools**: Choose from a pen, highlighter, eraser, and lasso tool for your drawings.
* **Full Customization**: Adjust the brush size and color to fit your style.
* **Undo and Redo**: Don't be afraid to make mistakes! You can undo and redo your actions at any time.
* **Document Management**: Save your masterpieces in JSON format and easily manage the pages of your documents.
* **Intuitive Navigation**: Explore your drawings with pan and zoom functions.

## 🛠️ Built With

* [Kotlin](https://kotlinlang.org/) - The official programming language for Android development.
* [Jetpack Compose](https://developer.android.com/jetpack/compose) - Google's modern toolkit for building native UI.
* [androidx.ink](https://developer.android.com/jetpack/androidx/releases/ink) - A library for low-latency digital ink input.
* [Kotlinx Serialization](https://github.com/Kotlin/kotlinx.serialization) - For serializing drawing data to and from JSON.

## 🚀 Getting Started

To build and run the project, follow these steps:

1.  Clone the repository:
    ```bash
    git clone https://github.com/valerioisufi/DrawView.git
    ```
2.  Open the project in Android Studio.
3.  Build and run the app on your emulator or Android device.
